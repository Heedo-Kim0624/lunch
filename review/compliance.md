# Compliance and privacy boundary

- No secrets, credentials, cookies, private messages, account pages, payment data, or precise location data were read or stored.
- Anonymous device IDs are generated in the browser and used only to associate pre-login recommendation feedback.
- Accounts store normalized email, display name, a password hash, revocable token, and recommendation behavior. Password plaintext is not stored.
- The MVP stores food-choice behavior; it does not collect protected health claims or infer allergies.
- Dietary restrictions and allergies must be implemented as explicit hard filters with clear user control before such data is collected.
- The included privacy page is an MVP disclosure. Operator identity/contact, retention, deletion, secure-cookie authentication, and legal review remain mandatory before inviting real users.
